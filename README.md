Minimal wrapper to make DualSense compatible with XInput to use with games that many PC games that don't support DualSense

Download the exe from https://github.com/ebraminio/ds2xi/releases/tag/latest and run it, it will add a tray icon

<img width="142" height="177" alt="image" src="https://github.com/user-attachments/assets/093f3971-a933-4c2b-adf4-9494b28ede9a" />

Left click to open joy.cpl (which shows gamepads state), right click to close the app.

To make it run on startup, run open shell:startup with Win+R and paste the exe in the folder.
